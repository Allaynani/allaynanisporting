AL LAYNANI SPORTING — ملفات الموقع
=================================

محتويات الحزمة
- index.html: الصفحة الرئيسية العربية.
- styles.css: التصميم المتجاوب.
- script.js: قائمة الهاتف والسنة الحالية.
- articles/: ثلاثة مقالات تأسيسية.
- about.html / privacy.html / disclaimer.html / contact.html: صفحات أساسية.
- assets/favicon.svg: أيقونة الموقع.

قبل النشر
1. افتح contact.html وindex.html واستبدل contact@example.com ببريدك الحقيقي.
2. أضف روابط حساباتك الرسمية واسمك وخبرتك الحقيقية.
3. راجع جميع النصوص. المقالات الحالية نقطة انطلاق وليست وحدها ضماناً لقبول AdSense.
4. إذا استخدمت صوراً لاحقاً، تأكد من امتلاك حقوق استخدامها وأضف النص البديل المناسب.
5. Google Fonts يستلزم اتصالاً بالإنترنت؛ إن لم يتوفر، سيستخدم الموقع خطوطاً احتياطية.
6. حدّث سياسة الخصوصية بحسب أدوات الإعلانات والتحليل التي تفعلها فعلياً.

نشر مجاني عبر GitHub Pages
1. أنشئ حساباً على https://github.com/
2. أنشئ مستودعاً عاماً جديداً (Public repository)، مثلاً al-laynani-sporting.
3. ارفع جميع الملفات والمجلدات كما هي، مع بقاء index.html في الجذر.
4. من Settings > Pages اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واحفظ.
5. انتظر اكتمال النشر. سيكون العنوان غالباً https://USERNAME.github.io/REPOSITORY/، حيث USERNAME اسم حسابك وREPOSITORY اسم المستودع.
6. افتح الرابط واختبره على الهاتف. لا تنشئ الرابط بالتخمين؛ استخدم العنوان الذي تعرضه GitHub Pages.

مهم حول AdSense
- الاستضافة المجانية لا تضمن قبول AdSense.
- لا توجد ضمانة للقبول أو الدخل. يلزم محتوى أصلي ومفيد، صفحات واضحة، تجربة جيدة، والامتثال لسياسات Google.
- لا تنقر على إعلاناتك ولا تشترِ زيارات وهمية.
- GitHub Pages خدمة استضافة ملفات ثابتة وليست نظام إدارة محتوى. لإضافة مقالات جديدة، أنشئ ملفات HTML جديدة واربطها من الصفحة الرئيسية، أو انقل المحتوى لاحقاً إلى Blogger/نظام إدارة محتوى.
- راجع شروط أهلية AdSense الحالية وبلدك قبل التقديم: https://support.google.com/adsense/answer/9724
